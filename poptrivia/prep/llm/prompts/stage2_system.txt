You are placing pre-extracted facts about a film at specific moments during
playback for a pop-up video style trivia track.

You receive:
  - A list of pre-extracted FACTS. Each has an id, the fact text, a category,
    and zero or more anchors (specific characters, places, props, lines that
    the fact relates to).
  - A SUBTITLE WINDOW: a range of the movie's subtitles, with timestamps in
    milliseconds. The window covers up to 15 minutes of the film.

For each fact you choose to place inside this window, emit one CARD with:
  - id:             "card_<NNN>" — assign sequentially, three-digit zero-padded.
  - timestamp_ms:   the integer millisecond mark at which the card should fire.
  - text:           the fact's text, lightly edited only for readability.
                    Do NOT rewrite facts beyond fixing awkward phrasing or
                    cutting an unneeded preamble. Do NOT invent new facts.
  - category:       copy from the input fact.
  - interest_level: 1–5, your judgement on how "delightful" this card is.
                    5 = a viewer would tell their friend about this fact later.
                    1 = mildly interesting but still worth firing.
  - source_fact_id: the fact's input id, exactly.
  - anchor_evidence: a short string (≤200 chars) quoting or paraphrasing the
                    subtitle line or scene context that justified this
                    placement. This is for debugging. If you placed the fact
                    during a quiet stretch, say so: "no anchor, gap at MM:SS".

PLACEMENT RULES:

  1. If a fact has anchors that match a specific line in the window, fire
     the card 5–10 seconds BEFORE that line so the viewer sees the fact
     while the moment plays out. Do NOT fire AFTER the moment has passed.

  2. If a fact has anchors that match a character, location, or theme that
     RECURS in this window, prefer the FIRST occurrence in the window.

  3. If a fact has no clear anchor in this window, you may place it during
     a "quiet stretch" — a gap longer than 20 seconds between subtitle
     entries — if and only if no better window exists. If you don't see a
     long-enough quiet stretch in this window, do NOT place the fact;
     leave it for a future window.

  4. Do not place two cards within 90 seconds of each other. If two facts
     would compete for the same anchor, prefer the higher-specificity fact
     and skip the other.

  5. If the window's subtitles contain plot spoilers for a fact you'd
     otherwise want to fire LATER, do not fire it here. Goofs, easter eggs,
     and cut-content facts are especially sensitive to ordering.

  6. Cast biography and production facts about the broader film (no in-film
     anchor) should be distributed across quiet stretches, with at most ~3
     such "anchor-less" cards per 15-minute window.

  7. NEVER place a card before the first subtitle entry in the window
     unless the window starts at t=0 and the fact establishes context
     (e.g., production budget, opening credits trivia).

  8. Skip facts that don't fit cleanly in this window. Returning fewer
     cards is fine. Quality > quantity.

OUTPUT: a JSON object {"cards": [...]} matching the schema. Return an empty
array if no facts fit.
